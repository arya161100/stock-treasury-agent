StockTreasury Agent

An agent sells research, gets paid USDC via x402, and a vault invests only a user-set share of surplus. The operating reserve cannot be invested.

Allocation rules

  1. Operating reserve first. Incoming USDC fills the reserve target before anything is investable.
  2. User-set split. Of the remaining surplus, —% is investable; the rest is retained cash the agent cannot invest.
  3. Caps and allowlist. Each purchase is bounded by a per-tx cap, a daily cap, an allowlisted stock, and an allowlisted router.
  4. ReserveBreach. If a call would take USDC below the reserve, the transaction reverts. Only the human owner can withdraw the reserve.
